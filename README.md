

# Finding PFAS in IM-MS/MS data

## `Predict_PFASinIMSMS.py`

This script performs **probabilistic PFAS screening** using a trained **mode-aware unified model bundle** (POS/NEG) generated by the corresponding training script.

It applies Monte Carlo (MC) uncertainty propagation on:

* `riMp1`
* `CCS_use`

and assigns each feature a **PFAS confidence level (0–3)** based on stored FDR-controlled thresholds.

---

# 1. Overview

`Predict_PFASinIMSMS.py`:

* Loads a trained unified bundle (`.joblib`)
* Applies MC prediction (uncertainty on riMp1 + CCS)
* Retrieves stored thresholds learned at specific FDR levels
* Assigns:

  * PFAS probability mean
  * Probability uncertainty (std)
  * Quantiles (e.g., p05, p50, p95)
  * PFAS confidence level (0–3)
* Outputs:

  * Full result table
  * Optional Top-N candidate table
  * Summary info

| ----------------------------- | --------------------------------------------- |
| `p_PFAS_mean`                 | Mean predicted PFAS probability (MC averaged) |
| `p_PFAS_std`                  | Standard deviation of probability             |

| `MZ_COL_used`, `CCS_COL_used` | Mode-specific columns used                    |

---

## PFAS Confidence Levels

Using two stored FDR thresholds:

* `low_fdr` (default 0.10)
* `high_fdr` (default 0.20)

Let:

* `t_low` = stricter threshold
* `t_high` = looser threshold
* `p_mean` = mean probability
* `p05` = 5% quantile probability

| Level | Condition            | Interpretation                             |
| ----- | -------------------- | ------------------------------------------ |
| 0     | Below all thresholds | Not PFAS                                   |
| 1     | `p_mean ≥ t_high`    | Candidate PFAS                             |
| 2     | `p_mean ≥ t_low`     | Medium confidence                          |
| 3     | `p05 ≥ t_low`        | High confidence (robust under uncertainty) |

Level 3 is the most conservative classification.

# 4. Command Line Usage

Basic usage:

```bash
python Predict_PFASinIMSMS.py \
  --model findingPFASinIMSMS.joblib \
  --input exp_features.xlsx \
  --mode pos \
  --out pred_full.csv
```

With Top-N output:

```bash
python Predict_PFASinIMSMS.py \
  --model findingPFASinIMSMS.joblib \
  --input exp_features.xlsx \
  --mode pos \
  --out pred_full.csv \
  --top-out pred_top.csv \
  --low-fdr 0.10 \
  --high-fdr 0.20 \
  --topN 200
```

Print run info:

```bash
--print-info
```

# 5. Parameters

| Argument         | Description                      | Default            |
| ---------------- | -------------------------------- | ------------------ |
| `--model`        | Path to unified `.joblib` bundle | Required           |
| `--input`        | Input feature table              | Required           |
| `--mode`         | `pos` or `neg`                   | Required           |
| `--out`          | Full output CSV                  | Required           |

| `--high-fdr`     | Higher FDR threshold             | 0.20               |
| `--topN`         | Number of candidates returned    | 200                |
| `--k-infer`      | MC repetitions                   | From bundle        |
| `--ri-noise`     | Relative uncertainty for riMp1   | From bundle        |
| `--ccs-noise`    | Relative uncertainty for CCS     | From bundle        |
| `--mc-quantiles` | Quantiles to compute             | (0.05, 0.50, 0.95) |
| `--seed`         | Random seed                      | From bundle        |

If MC parameters are not specified, values stored in the trained bundle are used.

# 7. Methodological Notes

### Monte Carlo Uncertainty Propagation

Each prediction is averaged over `K` perturbations:

* `riMp1 ← riMp1 * (1 + ε_ri)`
* `CCS ← CCS * (1 + ε_ccs)`
* ε ~ Uniform(−noise, +noise)

This accounts for:

* Cross-platform CCS variation
* Experimental riMp1 uncertainty

---

### FDR-Controlled Thresholding

Thresholds are learned on VALID data using:

> Maximize recall under FDR ≤ target

Stored thresholds ensure:

* Transparent operating point
* Controlled false discovery rate
* Mode-specific calibration

# 8. Typical Workflow

1. Train unified model
2. Apply prediction script
3. Filter:

   * Level ≥ 2 → medium confidence PFAS
   * Level = 3 → high confidence PFAS
4. Manually inspect top candidates

---

# 9. Recommended Screening Strategy

For exploratory NTA:

* Use `low_fdr=0.10`
* Review Level ≥ 1

For publication-level screening:

* Focus on Level ≥ 2
* Highlight Level 3 as high-confidence PFAS
